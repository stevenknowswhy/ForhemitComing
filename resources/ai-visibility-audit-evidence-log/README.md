# Free AI Visibility Audit Evidence Log

An ungated CSV template for recording manual checks of how AI answer engines describe a brand, cite sources, mention competitors, and handle buyer questions.

## What is included

- 18 evidence fields, including engine, model or mode, market, exact answer or reference, citations, competitors, factual accuracy notes, next action, owner, and next check date
- 12 neutral buyer-prompt starters across discovery, comparison, risk, and verification stages
- A portable CSV that works in spreadsheet tools without an account or integration

[Download the CSV](./ai-visibility-audit-evidence-log-template.csv)

## How to use it

1. Replace the bracketed placeholders in each prompt with your category, audience, market, brand, competitor, or requirement.
2. Run the prompt manually in the AI answer engines you want to evaluate.
3. Record the engine, mode, market, language, date, and exact answer or a durable reference.
4. Mark brand mentions and citations, then note competitors and any factual accuracy problems.
5. Choose one evidence-based next action, assign an owner, and set a date to check again.

Keep prompts neutral and record unfavorable results too. The log is most useful when the same prompts and observation method are repeated consistently.

## Boundaries

This template records manual observations. It does not run prompts, automate monitoring, calculate a universal visibility score, or guarantee citations, rankings, traffic, leads, or revenue.
